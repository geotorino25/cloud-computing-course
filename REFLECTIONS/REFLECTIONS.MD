# Cloud Computing Reflection Paper

### Prepared by: George Torino

Cloud computing plays an important role in my daily life because I regularly use online platforms for communication, entertainment, and productivity. Although I use these applications almost every day, I did not realize that many of them depend on cloud technology to function efficiently.

Three cloud services that I frequently use are Google Drive, Messenger, and Canva. Google Drive is classified as Software as a Service (SaaS) because it allows users to store, access, and manage files through the internet. It uses a public cloud deployment model because it serves millions of users around the world.

Messenger is also considered a Software as a Service (SaaS) application because it provides communication services through internet-connected devices. It operates mainly through a public cloud environment because it is available to anyone with an account.

Canva is another example of Software as a Service (SaaS) because it enables users to create and edit designs online. Similar to the other applications, Canva uses a public cloud model to provide its services to users worldwide.

Version control is essential because it helps developers monitor changes, fix errors, and restore previous versions of files whenever necessary. GitHub allows teams to collaborate more effectively by keeping an organized record of every modification made to a project.

As a student, learning how to use Git and GitHub will help me develop valuable skills that I can apply to future projects and professional work.
